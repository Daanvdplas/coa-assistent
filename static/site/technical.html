Hoe werken embeddings?How do embeddings work?

Je vraagt wanneer je met planten kunt werken. In de bron heet de activiteit tuinieren. Een klein model zet de tekst én je vraag om in lijsten getallen: embeddings. Voor de tekst en de vraag gebruiken we hetzelfde model. Zo kun je de getallen vergelijken.

You ask when you can work with plants. The source calls the activity gardening. A small model turns the text and your question into lists of numbers: embeddings. Both use the same model, so their numbers can be compared.

Vergelijk de betekenisCompare the meaning

Zie die getallen als plekken op een kaart. Verwante betekenissen liggen vaak dichtbij, ook als de woorden verschillen. De zoekfunctie kiest zo passende tekststukjes en geeft de oorspronkelijke woorden terug.

Think of those numbers as places on a map. Related meanings tend to be close, even when the words differ. Search uses this similarity to pick passages and return their original text.

Dit voorbeeld zoekt op betekenis. De demo kan ook op overeenkomende woorden zoeken.

This example searches by meaning. The demo can also match words.

Hoe gebruikt het model RAG?How does the model use RAG?

RAG betekent: eerst passende tekst opzoeken en die gebruiken voor een antwoord. Het antwoordmodel vraagt de zoekfunctie om passende tekst en krijgt die tekst terug. Het ziet gewone woorden, niet de getallenlijsten.

RAG means finding relevant text and using it to answer. The answer model asks the search function for relevant text and gets that text back. It sees ordinary text, not the lists of numbers.

Ontbreekt er iets? Het model kan de zoekfunctie om nog een tekststukje vragen.Missing a detail? The model can ask the search function for another passage.

Het model schrijft met de gevonden tekst een antwoord met bronnen. Een bron helpt je het antwoord te controleren, maar garandeert niet dat elke conclusie klopt.

The model uses the found text to write an answer with sources. A source helps you check an answer; it does not guarantee that every conclusion is right.
