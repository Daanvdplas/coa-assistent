How does a question find the right text?

You ask about working with plants. The activity is called gardening. The assistant finds related text, then gives it to the model that writes the answer.

This example searches by meaning. The demo can also match words.

1. Turn the text and question into numbers

A small model turns each source passage and your question into a list of numbers, called an embedding. Both use the same model, so their numbers can be compared.

2. Find text with a similar meaning

Think of those numbers as places on a map. Related meanings tend to be close, even when the words differ. The search uses this similarity to pick passages and return their original text.

3. Give the found text to the answer model

The answer model receives your question and the passages found by the search. It sees ordinary text, not the lists of numbers. It uses that text to write an answer with sources.

This is RAG: find relevant text, then use it to answer. A source helps you check an answer; it does not guarantee that every conclusion is right.
