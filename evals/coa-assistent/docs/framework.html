01

Execute the actual retrieval path

Local retrieval or a model session

Local retrieval evaluations search without an answer model. In the separate iterative-search route, Codex asks the Rust search function for evidence and writes an answer. MiniLM embeddings are local.

One question may need several searches

Codex can make a focused follow-up when evidence is missing, with at most four MCP search attempts. The current Rig website uses a separate direct callback, not this Codex/MCP route.

Exact rules and the saved example

This is T02, source ACT-FIETS-002. Time is in S2; indoors and address are in S3.

  • Goal 1: both S2 and S3.
  • Goal 2: S3.
  • Coverage: completely supported goals divided by two. S2 alone completes no goal.

In the saved example, the first search found only the bicycle time passage of these two required passages: 0/2 goals. A follow-up found the indoor/address passage: together 2/2. Those were two searches; a new model session can produce different queries, passages or scores.

Recomputing the same saved evidence gives the same score without a new search. A new model run can vary. Expectations are loaded for assessment, never supplied as search/model instructions.

03

Keep evidence and validity separate

Source support found

2/2 means both declared goals have complete evidence. It does not establish general answer quality.

Technical validity

Do source, date and exact quotes agree? Did the execution stay within limits? Failures and timeouts remain visible.

Retrieved evidenceSource and dateExact quotesSearch actions and status
This route does not automatically judge the meaning of the answer.

A technically valid run can score 0/2. A score of 2/2 does not prove faithful use of those sources.

What should a person check?

Does the suggestion satisfy Tuesday and indoors? Is gardening wrongly called an indoor activity? Is a schedule wrongly presented as a guarantee of current places?

Conditions and forbidden claims are predeclared, but this evidence calculation does not judge free-form answer meaning. T02 has no required unknown-answer criterion.

A separate optional AI judge exists for complete-assistant experiments; it is not used here. Without judgment, the native report retains its “Beoordeling nodig” status. Human calibration has not been performed.

Datasets and denominators
18 legacy questions

Twelve development/pilot questions and six predeclared comparison questions, over the same five documents. They are now seen development/regression cases.

8 judge-check candidates

Handmade answers, four for rubric development and four for checking. They are not eight extra retrieval questions; human labels remain empty.

5 earlier gardening cases

Historical regressions overlap the first pilot intents; they do not add five independent questions to the eighteen.

The current legacy P06 was revised on 16 November 2026. Original v1 and frozen independent questions retain their own identities. This explanation makes no claim that old scores measure the revision.

Questions and expectations live under evals/shared/datasets/. Missing positive evidence targets yield N/A, not perfect retrieval. A missed existing target gives zero coverage. Multiple valid alternatives use OR between groups and AND within a group.
