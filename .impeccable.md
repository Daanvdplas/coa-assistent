## Design Context

### Users
The project owner runs and presents activity-retrieval evaluations. They need to compare approaches and inspect the exact evidence behind differences.

### Brand Personality
Plain, calm, precise. The interface is COA Assistent, an independent prototype.

### Aesthetic Direction
Reuse the existing compact type, COA symbol and neutral surfaces. Use color only for meaningful state. Keep the evaluation environment separate from the demo and explanation pages.

### Design Principles
- Each fact, expectation and status appears once. Add results to the existing expectation.
- No unsolicited helper copy, introductions, repeated metadata or decorative cards.
- Start with a compact overview; keep evidence next to the selected question.
- Preserve historical evidence and make incompatible comparisons explicit.
- Keep keyboard, mobile, zoom and all run states usable.
